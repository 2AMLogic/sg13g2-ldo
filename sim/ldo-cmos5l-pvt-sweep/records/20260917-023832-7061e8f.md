### `Cc` value-tolerance window, at the corners that bind it

`cornerCAP.lib` maps every corner/mismatch/stat section to the
SAME nominal `cap_cmomi` model at this PDK's pin, so there is no
characterised MoM-cap corner spread to sweep -- and the PDK's own
documentation flags the model as not validated on CMOS5L silicon.
Tolerance to a wrong cap VALUE is therefore the only robustness
this caveat can be given, and it is measured here rather than
asserted: `Cc`'s width is swept at `ss`/125C against both resistor
sections that hold a worst case, with the loop-gain AND PSRR
benches run at every point. A small `Cc` fails from below (the
