SAME nominal `cap_cmomi` model at this PDK's pin, so there is no
characterised MoM-cap corner spread to sweep -- and the PDK's own
documentation flags the model as not validated on CMOS5L silicon.

asserted: `Cc`'s width is swept at `ss`/125C against both resistor
